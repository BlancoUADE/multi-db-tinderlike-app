COMO VERIFICAR EL PROYECTO MULTI-DB
===================================

1. Levantar contenedores

   docker compose up -d

2. Instalar dependencias en Python 3.11

   py -3.11 -m venv .venv
   .\.venv\Scripts\activate
   pip install -r requirements.txt

3. Verificar conexiones

   python tests\test_connections.py

   Debe mostrar:
   - PostgreSQL OK
   - MongoDB OK
   - Redis OK
   - Cassandra OK
   - Neo4j OK

4. Cargar datos demo

   python main.py
   Opcion 18: Cargar datos demo

5. Verificar datos por motor

   python tests\verify_databases.py

QUE MIRAR EN CADA BASE
======================

PostgreSQL
----------
Tablas esperadas:
usuarios, fotos, intereses, usuario_intereses, likes, bloqueos,
coincidencias, mensajes, eventos, asistencia_eventos, notificaciones.

MongoDB
-------
Colecciones esperadas:
perfiles_usuarios, sesiones_login.

Redis
-----
Claves esperadas:
session:{id_usuario}:{token}, user:{id_usuario}:unread_notifications,
user:{id_usuario}:likes_given, match:{id}:unread_messages:{id_usuario}.

Cassandra
---------
Keyspace: tinder_app
Tabla: mensajes_por_coincidencia

Neo4j
-----
Nodos: Usuario, Interes, Evento
Relaciones: DIO_LIKE, MATCH, TIENE_INTERES, BLOQUEO, ASISTE

FLUJO DE DEFENSA RECOMENDADO
============================

1. Mostrar que el CLI confirma las cinco conexiones.
2. Cargar datos demo.
3. Mostrar usuarios y perfiles.
4. Mostrar likes y matches automaticos por like reciproco.
5. Mostrar mensajes leidos desde Cassandra.
6. Hacer login, ver TTL en Redis y hacer logout.
7. Ejecutar verify_databases.py para ver la distribucion por motor.
